# Book Website working agreements

- CP means Commit Push. Commit and push only when explicitly requested, and always perform both through the GitHub Desktop application. Open it if closed; use the existing app if open. Never use terminal Git commands to commit or push.
- Preserve the approved master design backup in ../website-backups/approved master design. Never overwrite it.
- Make only changes requested by the user; preserve the approved photographs, colors, fonts, and layout outside that scope.
- Keep the site buildless and usable with a local static HTTP server.
- Use the existing hearttoheart-14e56 Firebase project for the Book Website contact form. Keep book-contact functions and records separate from main/support functions; reference the existing SMTP_URL secret without reading, copying, or replacing its value.
